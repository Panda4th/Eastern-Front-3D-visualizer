# historical/sources/

Historical Source の metadata を格納する namespace。

**現時点では空である。** Source ID 形式および metadata schema は Historical Data Model / Historical Source Acceptance Policy フェーズで決定する。

## 制約

- 史料原本ファイルを Repository へ格納することは Traceability の要件ではない。
- 原本ファイルを格納する場合は、再配布可能性を確認してからとする。
- 再配布条件が不明な地図・写真・スキャン史料・書籍 PDF を置いてはならない。
- 本 Repository は Public である。

詳細は [Project Foundation v0.1](../../docs/foundation/project-foundation_v0.1.md) §4 / §9、および [GitHub Cloud Development Foundation v0.3](../../docs/architecture/github-cloud-development-foundation_v0.3.md) §8 を参照。
