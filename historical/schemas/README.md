# historical/schemas/

Historical Data の schema 定義を格納する namespace。

**現時点では空である。** schema は Historical Data Model フェーズで決定する。

以下は本フェーズでは確定しない。

- Source ID 形式および immutability
- Confirmed / Estimated / Unknown のデータ状態モデル
- Historical Event の具体的な field 構成

詳細は [Project Foundation v0.1](../../docs/foundation/project-foundation_v0.1.md) §8.2 / §9 を参照。
