# historical/validation/

Historical Data の validation rule を格納する namespace。

**現時点では空である。** validator は Historical Data Model 確定後に導入する。

将来的な候補は以下。

- Schema Validation
- Source ID Validation
- Source Traceability Validation
- Broken Reference Validation
- Duplicate Source ID Validation
- Orphaned Historical Data Validation
- Required Evidence Validation
- Historical numeric change validation
- Source deletion / rename detection

詳細は [GitHub Cloud Development Foundation v0.3](../../docs/architecture/github-cloud-development-foundation_v0.3.md) §18 を参照。
